# Публикация темы Antonova Oksana

Публикуется не вся папка темы, а только рабочий пакет: PHP-шаблоны, CSS, JavaScript, иконки, сертификат, локальные шрифты и оптимизированные изображения. Исходники, PDF, README и служебные файлы на сервер не попадают.

Перед каждой публикацией GitHub Actions сохраняет текущую тему в соседнюю с темой папку `.antonova-theme-backups`. После успешной публикации остаются пять последних архивов. Затем `rsync --delete-delay` приводит папку темы на сервере в точное соответствие опубликованному пакету: устаревшие файлы удаляются только после передачи новых файлов и создания резервной копии.

## Откат

Откат выполняется только вручную по SSH, когда известно имя нужного архива. Это предохраняет рабочий сайт от случайного отката.

1. Подключитесь к Beget по SSH.
2. Перейдите в родительскую папку темы. Если тема находится в `.../wp-content/themes/antonova-theme`, это папка `.../wp-content/themes`.
3. Посмотрите доступные архивы:

   ```bash
   ls -lt .antonova-theme-backups/
   ```

4. Подставьте имя нужного архива вместо `ARCHIVE.tar.gz` и выполните:

   ```bash
   mkdir restore-antonova-theme
   tar -xzf .antonova-theme-backups/ARCHIVE.tar.gz -C restore-antonova-theme
   rsync -azc --delete-delay restore-antonova-theme/antonova-theme/ antonova-theme/
   rm -rf restore-antonova-theme
   ```

После отката проверьте главную страницу и страницу политики. Следующий обычный push в `main` снова опубликует актуальную версию из GitHub.
